## ⚡ გამოიყენე Claude Code-ში / Cursor-ში — MCP Server-ით ან CLI-ით

ეს მთელი კოლექცია ხელმისაწვდომია **MCP server-ად** — Claude Code-ის, Cursor-ის, Codex-ის ან ნებისმიერი MCP-თავსებადი client-ის შიგნიდან 378 რეპოს ეძებ ბუნებრივი ენით. ნაცვლად იმისა, რომ GitHub-ი გახსნა და README-ი დააქოქო, AI ასისტენტს ჰკითხე *"აი Pulse-ის კოლექციაში რა არის საუკეთესო RAG-ისთვის?"* — სწორ რეპოს ქართული აღწერით დაგიბრუნებს.

**MCP Install** — `~/.claude/claude_desktop_config.json` ან Cursor MCP settings-ში:

```json
{
  "mcpServers": {
    "aipulsegeorgia": {
      "command": "npx",
      "args": ["-y", "@aipulsegeorgia/mcp-server"]
    }
  }
}
```

**ან პირდაპირ ტერმინალში — `aipulse` CLI-ით** (MCP-კლიენტის გარეშე):

```bash
npx -p @aipulsegeorgia/mcp-server aipulse search "rag memory"
npx -p @aipulsegeorgia/mcp-server aipulse list --category coding
npx -p @aipulsegeorgia/mcp-server aipulse stats
```

ბრძანებები: `categories` · `list` · `search` · `get` · `stats` — ფლაგებით `-c/--category`, `-n/--limit`, `-l/--lang en|ka|both`, `--json`.

> *Available as an MCP server **and an `aipulse` CLI** — query 378 curated AI repos from Claude Code, Cursor, any MCP client, or straight from your terminal.* Full docs: [`mcp/README.md`](./mcp/README.md) · Source: [`mcp/`](./mcp/)
